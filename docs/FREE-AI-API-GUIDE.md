## 📝 Step-by-Step Guide

### **Google Gemini** (Easiest)
```
1. Go to: https://aistudio.google.com/app/apikey
2. Sign in with Google account
3. Click "Create API key"
4. Copy your key (starts with: AIza...)
5. Done! No credit card needed ✅
```

**Free Limits:**
- 15 requests/minute
- 1,500 requests/day
- 1M tokens/day (Flash model)

---

### **Groq** (Fastest)
```
1. Go to: https://console.groq.com/keys
2. Sign up with email
3. Generate new API key
4. Copy your key (starts with: gsk_...)
5. Done! ✅
```

**Free Limits:**
- 1,000 requests/day
- 200K tokens/day
- Ultra-fast inference (10x faster)

---

### **NVIDIA NIM** (Most Models)
```
1. Go to: https://build.nvidia.com/settings/api-keys
2. Sign in with NVIDIA account
3. Verify phone number
4. Create API key
5. Done! ✅
```

**Free Limits:**
- 132 models available
- 1M context length
- All modalities supported

---

### **Mistral AI** (Best for Europe)
```
1. Go to: https://console.mistral.ai/api-keys
2. Sign up with email
3. Generate API key
4. Copy your key
5. Done! ✅
```

**Free Limits:**
- 15 models
- 256K context
- No credit card

---

### **Hugging Face** (Open Source)
```
1. Go to: https://huggingface.co/settings/tokens
2. Sign in/create account
3. Click "New access token"
4. Select "Read" permission
5. Generate token
6. Done! ✅
```

**Free Limits:**
- 9 models
- 131K context
- Community models

## 🔐 Security Best Practices

```bash
# 1. Store keys in .env file
echo "GROQ_API_KEY=***" >> .env

# 2. Load in Python
from dotenv import load_dotenv
import os
load_dotenv()
key = os.getenv('GROQ_API_KEY')

# 3. Add to .gitignore
echo ".env" >> .gitignore

# 4. Never log API keys
# ❌ print(f"Using key: {key}")
# ✅ print(f"Using key: {key[:10]}...")
```
